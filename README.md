# HR Analytics Dashboard | Power BI

## Project Overview
An interactive HR Analytics Dashboard developed using Microsoft Power BI to analyze workforce data and uncover meaningful insights into employee demographics, attrition, job satisfaction, and organizational trends.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning & Transformation

## Dashboard Features
- Employee headcount and workforce overview
- Employee attrition analysis
- Department-wise employee distribution
- Gender and age-group analysis
- Job satisfaction and employee-related insights
- Interactive filters and visualizations
